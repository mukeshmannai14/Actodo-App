## 📌 About The Project

**Actodo** is a modern activity management web application built using **React.js** and **Tailwind CSS**.

The application provides a personalized dashboard where users can:

- Sign up
- Log in
- View their personalized dashboard
- See the current date and time
- Add daily activities
- View activities
- Delete activities
- Log out

This project was developed as part of my journey in learning **Frontend and Full Stack Web Development**.

# ✨ Features

## 🔐 Authentication

### Login

Users can log in using their username and password.

- Username input
- Password input
- Login validation
- Error message
- Signup navigation
- Dashboard navigation

### 📝 Signup

New users can create an account.

- Username registration
- Password registration
- Confirm password
- User state management
- Login navigation

---

# 🏠 Personalized Dashboard

After successful login, the user is redirected to a personalized dashboard.

The dashboard displays:

- 👤 Logged-in username
- 👋 Personalized welcome message
- 🕐 Live current time
- 📅 Current date
- ⚛️ Technology information
- 📋 Today's activities
- ➕ Add activity
- 🗑️ Delete activity
- 🚪 Logout

---
